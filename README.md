# riftipv6

Rift digests and ipv6 fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/riftipv6/

## Install / run

```bash
git clone https://github.com/theworker02/riftipv6.git
cd riftipv6
node src/cli.js
node --test
```
